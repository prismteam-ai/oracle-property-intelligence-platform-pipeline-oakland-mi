# Conditional media readiness

No recording, audio, narration, subtitle file, caption script, shot list or production media is created by this phase. The direct user gate requires both operator and external Lead greenlights before media work. The later packet's suggestion to prepare a script does not replace that gate. This is an evidence-readiness checklist only.

Before requesting that decision, verify:

- One frozen pair of source heads, contract, package, snapshot and deployed identities.
- A finite qualified source disposition, with every unmet positive expectation preserved.
- Fresh clean-browser/API access, mobile readability, map, MCP, lead and model receipts.
- A dedicated low-privilege review capability, isolation, expiry/rotation and retained-through date.
- Public/private field boundaries and reviewed screenshots free of protected rows or secrets.
- Real admitted source-backed examples with visible dates, uncertainty and empty-result limitations.
- Stable run history, historical public CID/CAR evidence and current local-only publication distinction.
- Cost/observability readbacks, independent review and temporary-access closeout.
- Operator and external Lead decisions recorded separately from technical test success.

A later authorized media phase can choose its story, click path, narration and captions against that frozen release. A readiness check is not media approval, a playable demo or official submission.
