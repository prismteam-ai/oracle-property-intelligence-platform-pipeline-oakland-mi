# Known limitations

The original open/long-open roofing-permit and uninterrupted-ownership outcomes remain source constrained. Acquired municipal records contain no explicit OPEN state or continuous lifecycle history. The complete available parcel/address source is not a complete permit or transfer-history source. The source inventory includes partial, metadata-only, unverified and access-blocked routes; it is not proof that all official alternatives are exhausted.

Roof age is a low-confidence building-year proxy where present, not an observed roof replacement date. Only 668 such proxies and 1,210 partial reported-sale observations are available in the protected model. Applicant/business license fields do not establish the listed contractor role, active eligibility or BBB facts. Those presence filters can correctly produce empty results.

The official place layer contains one quarantined Cass Lake anomaly and ambiguous City/Township names. A center-radius query does not implement an official polygon containment predicate. Public run 4 refreshed only selected public fields; private attributes retain older actual observation windows. Data assignments are conservative and unmatched source records remain private rather than being dropped or guessed.

CID1/CID2 are custom assessment-product snapshots. Local current Elephant CLI conformance, any local Atlas page and an IPNS observation do not establish Atlas publication or global synchronization. Run 4 is unpublished. External map/provider availability and AWS shared-account concurrency require observed runtime proof. Costs remain metered; Free plans and budgets do not guarantee zero spend.

The user requires both operator validation and independent lead agreement before media. A local review packet is not final submission or permission to push, publish or record media.

Rochester Hills source-labeled Owner observations are neither current legal-owner
verification nor ten-year tenure proof. Applied reports are not issued permits.
Printed PDF record/cost totals have documented discrepancies; the source values
and independently fenced record rows are retained without forcing reconciliation.
