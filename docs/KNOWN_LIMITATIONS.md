# Known limitations

The original criteria remain controlling. Current technical correctness does not establish complete county source coverage, authoritative current open permits, historical open continuity, roof installation dates, ownership continuity, verified contractor roles or reusable BBB ratings where the captured sources do not support those claims.

The accepted baseline includes partial municipal evidence and building-year proxies. A bounded current source campaign is reported independently with native fields, mappings, capture dates, rights and coverage denominators. Source data remains protected/private where required; no bulk provider export is exposed.

Current moving engineering guidance is pinned separately from the original assignment. GitHub-hosted CI cannot be claimed before a push. Internal metric/registry access has not been supplied. Current local CLI/Atlas artifacts are distinct from an external Atlas/global IPNS/MCP mutation. PagerDuty local mock acceptance is distinct from a live service test.

The designated PRs, final demo video, Ready-for-review transition and official submission remain later authorized work. No media approval is implied by a local test pass. Existing historical public gateway receipts are observations, not a continuous availability guarantee.
