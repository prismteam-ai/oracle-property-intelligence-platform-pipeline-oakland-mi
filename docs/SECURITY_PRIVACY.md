# Security and privacy

Public projection, protected operational intake, CRM leads, evaluator sessions and model ledgers are separate data classes. The public projection uses an explicit field allowlist; raw source JSON, postal-party data and vendor records remain outside model and public-publication allowlists. Authenticated typed API projections expose only explicitly described observations. Private source retention supports audit and future licensed enrichment without promoting uncertain roles into product facts.

The source adapter validates schema/count/native identity and retains hash-bound receipts. Protected cache manifests accept exact versioned roles, filenames, byte limits, schema/count/proof hashes and canonical manifest digests. Runtime rejects symlinks, hardlinks, foreign property IDs, duplicate IDs, source/projection mismatches and digest changes. DuckDB external access is locked after approved file paths are installed. Agent tools expose bounded contract queries rather than SQL, network, files or source-acquisition capabilities.

Hosted access uses signed, stored, revocable sessions and secure cookies. Read/write/model quotas have durable server enforcement; request bodies, radius/results, tokens and model costs remain bounded. The current shared P5 envelope permits 200 validated agent executions lifetime and 160/day, with 240 agent-endpoint attempts/day and 40/session-hour. Actual Converse calls remain capped at 100 lifetime, 80/day, 40/session-hour and $3 reserved incremental model spend. Earlier phase counters are preserved. Empty evidence invokes no model. Source result predicates and explicit sort order are validated before and after selection. Prompts cannot grant source access, role verification or arbitrary tools.

Use CSP/security headers, origin/CSRF/CORS checks, encrypted private storage and narrow resource policies. Budget alerts are notifications rather than hard spend stops. Final supply-chain, IAM, cookie/header, abuse and secret/private-data scan results must be read from the exact release receipts; this design description does not itself certify a deployment. Evaluator access secrets are delivered in a separate private guide, never this repository or the return ZIP.

Request accounting: the P5 durable request counter permits at most 200 validated agent executions lifetime and 160/day, including empty results and failed invocations. Pre-model refusals do not enter that execution counter. All agent-endpoint attempts, including refusals, consume the separate 240/day and 40/session-hour endpoint quota. Converse has its own durable limits of 100 calls lifetime, 80/day and 40/session-hour, with $3 reserved incremental spend. Failed or unmeasured calls retain their reservations; no counter is reset or refunded. Historical P3/P4 limits and counters remain those recorded for their original phases, not the current P5 envelope.

`ownership.reportedOwnerObservations` field before its first P5 deployment. The

unreleased draft. This adds private typed source observations without changing

minimized fact allowlist, which omits these names and raw source records. A
captured-provider regression checks both the retained private API observation
